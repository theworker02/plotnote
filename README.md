# plotnote

Plot identifiers and note tokens for idempotent workflows.

**Site:** https://theworker02.github.io/plotnote/

## Install / run

```bash
git clone https://github.com/theworker02/plotnote.git
cd plotnote
node src/cli.js
node --test
```
